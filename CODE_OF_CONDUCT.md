# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be welcoming and patient, especially with beginners. Every question is a fair question here. Criticize ideas, not people. Harassment, insults and discriminatory language are not tolerated.

**Reporting:** if someone's behaviour makes you uncomfortable, contact the maintainer privately through [GitHub](https://github.com/Kiddo4993). Reports will be handled confidentially, and maintainers may remove comments, commits or contributors that break these rules.
